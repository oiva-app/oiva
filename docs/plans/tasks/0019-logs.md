# Task 0019: Logs

**Branch**: `feature/logs`
**Depends on**: 0008
**Source**: [PRD](../../docs/prds/oiva-cli-v1.md) · **User stories**: 12

## What to build

`oiva logs` — a read-only command that shows CloudWatch application logs. Supports `--follow` for streaming and `--since` for time-windowed queries.

The command:

1. Reads the CloudWatch log group from Terraform output
2. Queries CloudWatch Logs `filter_log_events` or `get_log_events`
3. With `--follow`, polls for new events and streams them to the terminal
4. With `--since <duration>`, filters to events within the time window (e.g. `--since 30m`, `--since 1h`)
5. Auto-disables streaming and uses plain text when stdout is not a TTY
